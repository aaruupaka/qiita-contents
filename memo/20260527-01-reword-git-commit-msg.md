# 概要
gitのコミットメッセージを間違えた場合の対応手順

# 前提
リモートリポジトリへのpush前であること

# 手順
- rebaseコマンドを実行する。
    - 実行コマンド
        ```bash
        git rebase -i
        ```

- VSCode上でリストが出るので、変更対象のレコードの`pick`を`reword`と書き換え、閉じる。
- reword対象のコミットメッセージが表示されるので、都度書き換え、閉じる。
- 現在のコミットのログを表示する。
    - 実行コマンド
        ```bash
        git log --oneline -10
        ```
    - 備考
        `-10`部分は表示件数。必要に応じて変更する
