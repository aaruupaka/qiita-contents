# worklogs

作業時点で、記事化する予定のない作業および検証に関する。ログを管理するディレクトリです。

## 目的

- 作業手順の記録
- エラー対応履歴の保存
- 検証結果の保管
- 一時的なメモや試行錯誤の記録

## 管理方針

- 原則として日付ベースでディレクトリを作成する
- 作業単位でディレクトリを分割する
- 公開予定のない内容も含む
- 必要に応じて articles/ 配下へ移行する

## ディレクトリ構成例

```text
worklogs/
└── 20260518-01-private-article-migration/
    ├── index.md
    └── images/
```
