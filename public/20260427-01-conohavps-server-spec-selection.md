# はじめに
ConohaVPSで契約するサーバーのスペック検討した際の記録を記載した記事です。
<br>
ConohaVPSで初めて契約する人の検討の参考になれば幸いです。

# 前提
- 2026年4月に検討した内容内容です。
- 料金等は変更される可能性あります。
- 記事作成時点においては、初回料金割引キャンペーンが実施されています。
  - 最大70%割り引かれるようです。
  - 検討料金については割引前の金額で検討しています。

# 使用用途
私は現在、下記の使用用途を想定しています。
- Blog（wordpress）
- データアナリストへの転職を想定したポートフォリオの設置
- 個人利用向けのWebアプリケーション
- 検証用アプリケーション

おもにBlogを運用する予定でいます。
<br>
また、個人的な事情ですが、
現在、データアナリストへの転職を検討しています。
<br>
データアナリストへの転職活動用に、ポートフォリオを作る予定でいるため、
そちらも掲載する予定でいます。
<br>
ポートフォリオはBlog上で掲載する可能性もありますが、
そもそもの問題としてどのようなポートフォリオを作ればいいかわかっていないので、
柔軟に対応できる形にしようと考えています。
<br>
また、気分転換に、個人利用向けのWebアプリケーションを開発しようかなと考えています。

# その他・所感
- メモリ4GBは、金銭的にきついように感じました。
  <br>
  一時的には問題ないものの、継続的に支払うことを考慮すると、高いように感じています。
  <br>
  また、現時点ではマネタイズできる見込みもないので、費用は下げたほうが良いように思いました。
- 運用する覚悟を決めるため、1年プランで契約しようと考えました。
  <br>
  少なくとも、1年間はブログは運用してみようと考えています。
- 勘であり明確な根拠はないものの、1GBはWebアプリケーションをリリースするとスペックが不足しそうな気がしています。
  <br>
  ブログのPVが伸びた場合や、個人利用向けWebアプリケーション等の容量が多くなった場合はサーバーはサーバーを分離しようと考えています。
  <br>
  しかし、現時点では、費用圧縮のため、同一サーバーで運用する予定です。

# 結論
**メモリ2GB**を契約することにしました。
